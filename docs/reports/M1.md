## Least sure layer classifications
1. Fascia/aponeurosis items (`fascia`, `aponeurosis` in the superficial list): all marked superficial by name; some may be deep.
2. Deep versus superficial for the many hand and foot muscles: only a few are listed, so the rest default to deep.
3. `orbicularis` (all of them) is superficial; orbicularis oris and oculi are fine, others are unchecked.
4. Facial muscles other than frontalis, occipitalis, orbicularis, masseter, temporalis, platysma default to deep.
5. Tendons: only 8 tendon parts exist; `intermediate tendon` is marked deep.

## Open questions
- Is the layer list (`superficial` in config.json) good enough, or should depth come from mesh data in a later milestone?
- Vitest 5 only installs with `npm install --legacy-peer-deps` on npm 10.8.2 (npm crash on the peer set). On Node 20 the vitest reporter crashes with `Map.groupBy` when a test fails.
- trimesh vertex normals need scipy (not a listed dependency), so build.py computes area-weighted normals itself.
- ponytail: one material per mesh (about 690 draw calls). If Android fps is below 30, move to BatchedMesh in M2.
